# Alola Packing List (باكينج ليست — شركة العلا)

Static PWA (no build step). Render Static Site: build command `true`, publish directory `.`.
Login via the shared alola-maggi-auth API (app id `packing`).
The PDF embeds `ALOLADATA1` load data (PDF Keywords + invisible text) so Al-Ola Station 1.3.0 imports it as a packing list.
